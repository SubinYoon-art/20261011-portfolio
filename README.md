# Portfolio Quest — Subin Yun

파스텔 커팅 매트 위에서 자수 패치를 모으고, 다마고치 펫을 키우며 탐험하는 UI/UX 디자이너 인터랙티브 포트폴리오.
빌드 도구 없이 `index.html` 을 브라우저로 열면 바로 동작합니다.

## 구조
- `js/data.js` — **콘텐츠는 여기만 수정**: 프로필/연락처, 패치(프로젝트), 스킬 수치, 퀘스트, 레벨 기준
- `js/pixel.js` — 픽셀 펫 스프라이트, 도트 숫자, 자수 패치 SVG 생성기
- `js/app.js` — 게임 상태(localStorage 저장), 드래그/물리, 패널, 레벨업
- `css/style.css` — 스타일

## 플레이 요소
- 패치 클릭 → 프로젝트 파일(폴라로이드·라벨 테이프·스탬프) 열람, 스킬 트리 공개
- 패치를 끌어 출입증에 붙이기 / 출입증 끌어서 흔들기 / 클릭해서 뒤집기
- DESIGN·GOTCHI: 밥·놀기·상태 — 알 → 말랑이 → 새싹 → 베레모 → 마스터 (Lv.1~5)
- Lv.5 달성 시 VIP 홀로그램 출입증 + 이력서 버튼 해금
- 하단 탭: 퀘스트 영수증, 캐릭터 시트, 연락처 엽서, 사운드 토글
- 숨은 무당벌레 🐞
